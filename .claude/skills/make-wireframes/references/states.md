| State | Must show |
|---|---|
| normal | real data, primary action visible without scrolling on mobile |
| loading | skeleton or spinner in place of content; actions disabled; no layout jump |
| empty | why it's empty + the action that fills it ("No bookings yet - Book a slot") |
| error | what went wrong in plain words + how to fix / retry; keep user's input |
| success | confirmation of what happened + next step; undo for risky actions |
